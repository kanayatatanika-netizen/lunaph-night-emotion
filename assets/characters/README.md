ここに完成したキャラクター画像を置くと、診断結果ページへ自動反映されます。

推奨:
- PNG または WebP
- 透過背景
- 正方形または縦長
- 1200px以上

現在の正式キャラクター:
- meroa-character.jpg: めろあ / 愛情
- furomu-character.png: ふろむ / 恐怖
- cres-character.jpg: くれす / 孤独
- michiru-character.png: みちる / 自由
- kuyuri-character.png: くゆり / 後悔

同名の `.webp` を使う場合は `outputs/app.js` の該当パスだけ差し替えてください。
